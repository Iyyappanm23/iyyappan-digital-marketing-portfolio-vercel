# Iyyappan M — Digital Marketing Specialist Portfolio

A responsive dark-premium portfolio built with React, TypeScript and Vite.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in VS Code.
3. Open Terminal in the folder that contains `package.json`.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Personalize before publishing

- Replace the LinkedIn URL in `src/App.tsx` with your exact public LinkedIn profile URL.
- Add your professional photo if you want one; the current hero uses an initials-based visual.
- Check all dates and role descriptions for accuracy.
- The resume PDF is stored in `public/Iyyappan-Digital-Marketing-Resume.pdf` and is linked from the Resume buttons.
- Project descriptions are experience summaries, not claims of specific campaign results. Add verified metrics only when you have them.
